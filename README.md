# План проекта: Крестики-нолики (Tic-Tac-Toe) на C++

## Описание и цель
Я начинаю изучать C++ и решил, что лучший способ закрепить базовую теорию — сделать практический проект с нуля. В качестве своей первой программы я выбрал консольную игру «Крестики-нолики».

Моя главная цель — поэтапно разобраться, как строится логика приложения, как работать с простейшими структурами данных и как переносить идеи в работающий код.

---

## Мой Roadmap

###  Шаг 1: Создание игрового поля (В процессе)
 **Задача:** Нарисовать в консоли сетку 3х3 и заполнить ее стартовыми значениями.
 **Что предстоит освоить:** Работу с двумерными массивами (`char board[3][3]`), циклы `for` и форматированный вывод данных в терминал (`cout`).

###  Шаг 2: Взаимодействие с игроком
 **Задача:** Научить программу принимать номера клеток от пользователя и ставить туда 'X' или 'O'.
 **Что предстоит освоить:** Обработку ввода (`cin`), условные операторы `if/else` (для проверки, не занята ли клетка) и базовую математику (для перевода чисел 1-9 в индексы массива).

###  Шаг 3: Игровой цикл и проверка победы
 **Задача:** Сделать так, чтобы игра продолжалась до победы или ничьей, и правильно определять победителя.
 **Что предстоит освоить:** Главный цикл программы (`while`), логические операторы (`&&`, `||`) и декомпозицию. Я планирую вынести повторяющийся код в отдельные функции, чтобы не писать всё сплошным текстом в `main()`.

###  Шаг 4 (Продвинутый): Добавление ИИ
 **Задача:** Когда базовая игра на двоих заработает, я хочу сделать режим "Игрок против компьютера".
 **Что предстоит освоить:** Генерацию псевдослучайных чисел для ходов компьютера. В перспективе — попробовать написать алгоритм, чтобы компьютер не просто ходил наугад, а пытался блокировать выигрышные комбинации игрока.

## Текущий прогресс


```cpp
#include <iostream>

using namespace std;

int main() {
    setlocale(LC_ALL, "Russian");

    char board[3][3] = {
        {'1', '2', '3'},
        {'4', '5', '6'},
        {'7', '8', '9'}
    };

    cout << "Крестики-нолики" << endl << endl;

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            cout << " " << board[i][j] << " ";
            if (j < 2) cout << "|";
        }
        cout << endl;
        if (i < 2) cout << "---+---+---" << endl;
    }

    int row, col;
    cout << endl << "Введите номер строки (0-2) и столбца (0-2) для хода X: ";
    cin >> row >> col;

    board[row][col] = 'X';

    cout << endl;
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            cout << " " << board[i][j] << " ";
            if (j < 2) cout << "|";
        }
        cout << endl;
        if (i < 2) cout << "---+---+---" << endl;
    }

    return 0;
}
